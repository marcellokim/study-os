# Source drop zone

Put real course materials for this course under these folders:

- `syllabus/` — syllabus or exam-scope documents
- `slides/` — original slide PDFs or exported slide text
- `transcripts/` — lecture transcripts or OCR text
- `images/` — extracted diagrams, charts, tables, handwritten notes, or formula screenshots
- `notes/` — your own notes and annotations

For an actual course, keep the folder name aligned with `course.course_slug` in your init request. Example: if `course_slug` is `software-engineering-midterm`, use `courses/software-engineering-midterm/sources/`.
